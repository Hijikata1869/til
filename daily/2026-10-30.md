わからない：なぜnumericalityの内側にallow_nilを書かなきゃいけないか？

```:ruby
# 非推奨
  validates :weight, numericality: { greater_than_or_equal_to: 0, less_than: 1000 }, allow_nil: true
```

```:ruby
# 推奨
  validates :weight, numericality: { greater_than_or_equal_to: 0, less_than: 1000, allow_nil: true }
```

【本質】
allow_nil: trueを最後に書くと、それがバリデーション全体に適応されるから。今回の場合バリデーションが１つだけだから最後に書いても意図通り動作するけど、これが例えば

```:ruby
  validates :weight, numericality: { greater_than_or_equal_to: 0, less_than: 1000 }, presence: true, allow_nil: true
```

のような場合だとpresence: trueにもallow_nil: trueが掛かってしまい、presence: trueを指定しているのにも関わらず、nullが許可される、という動作になってしまう。

【使い分け】  
バリデーションが１つまたは全部にnullを許可したい　→最後に書いても良い  
バリデーションが複数　→効かせたいバリデーションの内側にallow_nilを書く
